# Growth Desk · 涨粉作战台

小红书 / 公众号 / 视频号创作者的手机工作流：账号定位 → 选题 → 内容包 → 发布检查 → 数据复盘。

**在线使用：** https://vcdwio.github.io/growth-desk/

- 任何手机浏览器打开即可，建议「添加到主屏幕」，断网也能用
- 记录保存在本机浏览器；换手机用「备份与换手机」里的备份码
- AI 生成：复制提示词到豆包 / Kimi / DeepSeek 等，再把回复粘贴回来
- 发布始终由你本人在平台 App 内手动完成；AI 生成的图片/视频请勾选平台的 AI 内容声明

本仓库只存放构建产物（`index.html`、`manifest.webmanifest`、`sw.js`、图标）。
